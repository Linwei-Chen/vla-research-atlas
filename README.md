# VLA 部署期在线适应与持续学习研究地图

> 按更新信号与部署闭环强度，从即时上下文适应下钻到长期持续学习

[在线阅读](https://linwei-chen.github.io/vla-research-atlas/) · [综合报告](docs/REPORT.md) · [浏览结构化数据](https://github.com/Linwei-Chen/vla-research-atlas/blob/main/atlas.json)

该领域的关键差异不是模型规模，而是部署时什么发生变化：上下文、语言提示、少量任务数据、交互轨迹、策略参数或可扩展模块。地图以决定性更新信号划分五条路线，并以更新发生的时间尺度划分四级闭环。直接 VLA 证据目前集中在少样本后训练、在线强化学习和适配器式持续学习；实体机器人、长期开放世界和安全触发的联合证据仍稀疏。

## 路线导航

| 路线 | 主要关注点 |
|---|---|
| 上下文、检索与语言转向 | 冻结底层 VLA，通过示例检索、历史上下文或动态语言反馈改变当前行为。 |
| 少样本参数适配 | 用少量目标任务或部署数据更新全部参数、低秩参数或动作头，使通用策略贴合新任务、环境或具身。 |
| 人类介入与纠错学习 | 从部署中的接管、纠正和隐式信任信号学习，同时控制监督负担与劣质干预的影响。 |
| 奖励驱动在线后训练 | 利用在线交互、过程奖励、价值估计或自蒸馏突破行为克隆上限。 |
| 持续积累与抗遗忘 | 在任务序列中积累新技能，通过数据循环、模块扩展、路由或受控更新保持旧能力。 |

## 如何阅读

1. 打开[在线地图](https://linwei-chen.github.io/vla-research-atlas/)，先从“路线 × 层级”总览判断领域结构。
2. 用关键词和出版状态缩小范围，再点击聚合节点比较同一分支中的工作。
3. 进入详情页，按“问题—机制—证据—局限—启示—来源”下钻到单项工作。
4. 需要完整论证时，继续阅读[综合报告](docs/REPORT.md)与[检索与证据审计](docs/SEARCH_AUDIT.md)；需要二次分析时使用 `data/` 导出。

页面不依赖服务端。克隆仓库后可直接双击 `index.html` 离线阅读；论文原文、代码和数据集等外部链接需要联网。

## 研究范围与证据边界

L1 结构化范围扫描。纳入直接研究 VLA 部署期适应的工作，以及少量不可替代的在线机器人学习桥接证据；排除只有离线预训练或零样本泛化、没有部署期更新机制的工作。检索截至 2026-08-09，不声称穷尽。

地图把出版状态、阅读优先级、证据质量和展示层级分别记录，避免把“已发表”“重要”“证据强”或“工程成熟”混为一谈。详情页中的机制图是依据文字证据绘制的解释性示意，不替代原论文图表或独立复核。

## 项目文件

- `index.html`：交互式研究全景、路线说明、时间线与完整索引。
- `paper.html?id=...`：每项工作的机制、证据、局限和一手来源详情。
- `atlas.json`：人工维护的结构化研究真源。
- `docs/REPORT.md`：领域综述、关键分歧、时间线与开放问题。
- `docs/SEARCH_AUDIT.md`：检索范围、纳排规则、覆盖限制和反证记录。
- `data/papers.json`、`data/papers.csv`、`data/references.bib`：便于阅读、分析与引用的导出。
- `planning/` 中公开的账本文件：范围合同、查询、筛选和核心主张的可追溯记录。

## 数据更新与复核

网页和数据导出由 [`build-research-atlas`](https://github.com/Linwei-Chen/build-research-atlas) 从 `atlas.json` 确定性生成。更新记录后，应重新编译并执行严格验证与真实浏览器回归；不要直接改写 `data/` 中的派生文件。

这是一份有明确截止日期和纳入边界的研究综述，不声称覆盖互联网上的全部长尾资料。若发现题名、状态、链接或证据表述需要修正，欢迎在仓库中提交问题并附一手来源。
